# UttarPradesh.org - Foxiz Capital Theme Demo

A high-performance, modern news and media portal demo for **UttarPradesh.org** inspired by the **Foxiz Capital** newspaper template, built using pure **HTML5, CSS3, and JavaScript**.

## 🌟 Key Features

- **Foxiz Capital Layout**:
  - Center brand logo with newspaper-style grid.
  - 3-column signature hero section (Lead story + dual sub-features, central vertical reports with dashed dividers, trending numbered popular list).
  - Clean typographic hierarchy with Playfair Display, Rozha One, Google Sans, and Noto Sans Devanagari.
- **Real Content from UttarPradesh.org**:
  - Authentic news stories (Jalaun, Chitrakoot, Mau, Varanasi, etc.).
  - UP MLAs and MPs political directory and political journeys.
  - Video lounge and ground reports.
  - Panchayat Election 2026 voter list statistics.
  - Assembly Elections 2027 strategic analysis.
- **Interactive Features**:
  - 🌓 **Dark / Light Mode**: Seamless theme switching with automatic logo adaptation (`uplogo.svg` / `logo-white.svg`) and `localStorage` persistence.
  - 🔍 **Live Instant Search**: Real-time search across Hindi and English titles, excerpts, and tags.
  - 📑 **Saved Articles / Bookmarks**: Persistent bookmarking with counter badge and side drawer.
  - 📖 **Article Full Reader Modal**: Complete reading experience with font zoom controls (`A-` / `A+`) and social sharing (WhatsApp, X, Copy Link).
  - 🏛️ **Politicians Showcase**: Interactive tabs to filter between Samajwadi Party, BJP, MLAs, and MPs.
  - 🎬 **Video Player Modal**: Video bulletin showcase.
  - 📰 **Breaking News Ticker**: Smooth animated marquee with pause-on-hover.
  - 📬 **Newsletter Subscription**: Responsive subscription form with instant feedback.
  - 📱 **Offcanvas Mobile Drawer**: Fully responsive mobile navigation.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve it using any static HTTP server:

```bash
# Using Python
python -m http.server 3000

# Using Node.js
npx serve .
```

Then visit `http://localhost:3000`.
